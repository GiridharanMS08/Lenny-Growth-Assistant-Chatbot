# Coding-agent logs

This folder records engineering attempts relevant to the submission, including failed approaches and their corrections.
Logs are intentionally sanitized: no API keys, passwords, tokens, database credentials, or private user prompts are stored.

For this take-home, the logs emphasize:
- preserving the existing retrieval/configuration contract;
- performance improvements that do not change `TOP_K`, reranking, or generation limits;
- PostgreSQL verification;
- security and operational corrections.
